# Quran House — Project Specification

## Status
Pre-development. This document defines the initial product direction only; it does not authorize feature implementation.

## Product Goal
Quran House is a customizable Quran short-video generator designed to create polished vertical videos from Quran verses, recitations, translations, visual backgrounds, and reusable visual themes.

## Core Product Direction
- Quran verse and translation retrieval.
- Multiple Quran reciters/audio sources.
- Reusable visual themes/templates.
- Background media selection, initially with Pexels as a planned provider.
- 9:16 short-video composition.
- Arabic verse typography with translation.
- Progress indicator and subtle channel branding.
- Automated quality validation before export.
- Future AI-assisted verse/theme understanding and workflow automation.

## Initial MVP Boundary
The first working milestone is intentionally small:

> Given a selected verse, generate one valid 9:16 Quran video containing the Arabic verse, a translation, recitation audio, a background, and the basic visual layout.

## Planned Evolution
1. First working video.
2. Reusable theme system.
3. Multiple reciters and audio handling.
4. Intelligent/semantic background selection.
5. AI-assisted theme selection.
6. Guard/quality agent.
7. Batch generation.
8. Workflow automation.
9. V1 release.

## Explicit Non-Goals for Early Development
- Building a production SaaS platform.
- Premature databases or complex backend infrastructure.
- Building an unnecessarily generic video framework.
- Adding AI where deterministic logic is sufficient.
- Expanding scope before the current milestone is stable.

## Working Principle
Build the smallest useful thing first, verify it with evidence, then expand. The visual output is a first-class success criterion for this project.
