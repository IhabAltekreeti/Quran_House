# Quran House — Milestones

## M0 — Foundation
**Goal:** establish the project structure, working protocol, and development environment.

**Exit condition:** repository and project workflow are ready for implementation.

## M1 — First Working Video
**Goal:** generate one valid 9:16 Quran video from a selected verse.

**Acceptance:** Arabic verse, translation, recitation, background, basic layout, and valid MP4 output.

## M2 — Theme Engine
**Goal:** support reusable visual themes without rewriting the core pipeline.

## M3 — Audio & Reciters
**Goal:** support multiple reciters and robust audio handling.

## M4 — Intelligent Backgrounds
**Goal:** select relevant background media using deterministic and/or semantic signals.

## M5 — Quality Guard
**Goal:** automatically validate generated videos before approval/export.

## M6 — Batch Generation
**Goal:** generate multiple videos reliably from a defined input set.

## M7 — Automation
**Goal:** make the generation pipeline suitable for repeatable workflow automation.

## M8 — V1 Release
**Goal:** publish a stable, documented, usable Quran House V1.

## Milestone Rule

A milestone is complete only when its acceptance criteria are demonstrated with evidence. A feature being coded is not the same as a milestone being complete.
